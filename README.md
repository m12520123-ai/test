# SwingLab V2.3 - 自動分析入口

## 更新方式
將本壓縮檔最外層的 index.html 上傳至 GitHub Pages 原網站發布目錄，覆蓋舊首頁。
這份首頁已內含 CSS 與程式，不需另外上傳 source 資料夾。
人體模型仍需網路載入，不是完全離線版。使用原本 HTTPS 網址，不要直接在手機檔案程式開 HTML。
原有 v2 本機紀錄不會因這次更新自動刪除。

## 操作
預設第一頁是自動分析。上傳影片後會自動掃描，也可取消「選完就自動開始」，再按「一鍵自動分析」。
相機模式保留即時人體分析與倒數錄影；停止錄影後自動接回同頁影片掃描。
自動結果包含：有效人體畫面、關節角度範圍、手腕中點路徑、手部影像移動曲線、手部最高位置與移動最快時點。
自動影片最長 120 秒，最多 900 個取樣時點。長影片會降低取樣率，並非每影格都分析。
變速或慢動作影片需設定倍率；多倍率片段請先裁切。

## 球路、速度與桿面的實際範圍
- 球路自動搜尋是實驗性白色小物件追蹤，不是已訓練的高爾夫球辨識模型。紫色虛線均為未確認候選。請確認是球後才保留。
- 不補畫被遮擋或畫外的球路，不產生 Carry、Spin、球速等猜測值。
- 手部移動速率以「%畫寬/實際秒」呈現，不是桿頭速度，不填入雷達 Club Speed 欄位。
- 手部最高位置不一定是上桿頂點；手部移動最快時點不一定是擊球瞬間。
- 桿頭速度與真實桿面開閉角未完成自動量測。原手動校正工具保留在進階區。
