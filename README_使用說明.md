# SwingLab v2.2 影片功能修正版

## 這次只要替換 index.html
解壓縮後，將最外層的 `index.html` 上傳到原本 GitHub Pages 的發布資料夾，覆蓋舊的首頁。
首頁已包含全部介面樣式和程式碼，不再依賴另外上傳 js/ 或 CSS，避免新舊版混用。
原本的紀錄資料庫名稱保留，沒有清除資料的升級程式。仍建議先備份重要影片。
不要把 source/index.html 當成最外層的 index.html 上傳；source/ 僅供程式開發使用。
開啟原本的 HTTPS 網址，在「彈道與桿面」的分析工具區應看到 V2.2。沒看到請重新整理。

## 上傳後如何操作
- 球路：選「01 球路」，點畫面中球的位置，按「下一個時間點」後再點球。每個時點一點，下方球路圖立即連動。同時點重點為修正位置，不是新增另一點。
- 桿速：選「02 桿速」，點已知長度參考物的兩端、輸入實際 cm；再按「02 桿速」切換至桿頭標記，在不同時間點選真正的桿頭。完成後就有區間速度曲線。參考物與運動桿頭需在相近深度，相機需固定。
- 桿面方向：「03」先畫目標方向的兩點，再按「03」畫桿面朝向的兩點。下方顯示手畫方向夾角。
- 人體姿態：「04」載入 MediaPipe 分析目前畫面，也可設區段掃描。這一項需聯網下載模型；失敗時其他手動工具仍可使用。

可回放、調整播放速度、以時間步距前後移動、檢查標記表格、刪除單點與復原，並可匯出標記 PNG、CSV、完整分析 JSON 與原始影片。
儲存需瀏覽器允許本機儲存；與瀏覽器清理資料等操作有關，請定期匯出備份。

## 修正範圍
1. 將上傳影片的標記直接連到下方圖表，不再只看到需外部數據的空儒表。
2. 手機標記按鈕移到影片旁，加上需要幾點、缺少什麼的提示。
3. 將影片 metadata 讀取與首幀解碼分開，避免按鈕一直鎖著。還沒解碼的畫面不會讓你標記錯幀。
4. 取消 AI 掃描後立即解鎖手動工具，不會因模型下載中卡住全頁。
5. AI 使用已凍結的畫面，不會在模型載入後誤分析另一個時點。
6. 替換影片時清除舊結果，不清除已儲存紀錄。

## 不能把下列事情當成已完成
此版不是「上傳就自動產生雷達數據」。
球路是手動標點的影像軌跡；桿速是校正後的二維投影區間平均；桿面是人工方向線的夾角。
不產生自動測得的 Carry、Spin、三維 Face Angle；下方進階區保留外部數據手動輸入，與影片結果分開。
相機、AI 載入與真實揮桿辨識仍需在實際 iPhone 確認；此版沒有宣稱已通過實機精度驗證。
