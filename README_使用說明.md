# SwingLab v2.1 - 彈道與桿面：同頁影片／相機版

## 這次的更新
進入「彈道與桿面」，直接切換「上傳影片」或「手機相機」，不需切換到其他頁面。原本的即時攝影、影片分析分頁也保留。

### 上傳影片
點「選擇影片」→回放或使用時間步距定位→標記球路／桿頭／桿面方向→儲存分析。

### 手機相機
點「開啟相機＋分析」→允許鏡頭→即時顯示人體姿態→三秒倒數錄影→停止→自動接回同頁的回放標記區。
相機錄影與人體模型載入已分離；AI 尚未載入或失敗，仍可先錄影。不會假裝已有姿態數據。
切換來源或離開分頁會關閉相機；錄影中切換會先詢問是否停止。

## 測量邊界
- 即時自動分析的是人體姿態。本版沒有自動追蹤快速球體或桿面的專用模型。
- 黃色球路線是不同時點手動標記後的影像軌跡，不是三維彈道。
- 桿頭投影速度需先標示同深度的已知長度，再於不同時點點桿頭，並設定正確慢動作倍率。顯示的最大值是標記時段的平均速度峰值，不是真實擊球瞬時速度。
- 「目標方向」和「桿面朝向」各由兩點建立箭頭，計算其在畫面上的有號夾角（逆時針為正）。必須手動判讀方向；桿面朝向不是桿面邊緣。此值不等於真實 Face Angle，不會判定開面／關面。
- 上述影像推估不會寫入雷達 Club Speed、Face Angle、Ball Speed、Spin 或 Carry 欄位。
- 原本 3D 彈道示意與外部擊球參數，移至下方「外部量測／手動擊球數據」展開區，與影像標記分開。

## 六個分頁

### 1. 練習總覽
- 深色響應式介面，桌面側邊選單／手機底部導覽。
- 3D 透視、側視、俯視練習場示意與球路動畫。
- Carry、Total、Club Speed、Ball Speed、Smash Factor。
- Launch、Attack、Spin、Spin Axis、Apex、Flight Time、Offline、Club Path、Face Angle、Launch Direction、Face to Path。
- 最近擊球選取、依球桿篩選、目標距離設定。
- 落點散布圖、1 個標準差橢圓、平均／最低／最高／有效筆數及趨勢線。
- 缺少數據一律顯示「—」，不以預設假值填空。

### 2. 即時攝影
- 手機前／後鏡頭、Face-on／Down-the-line、球桿選擇。
- 懶載入 MediaPipe，模型失敗不會讓整個網站失效。
- 人體骨架、左右手肘／膝角度、軀幹投影傾角、頭部水平位移。
- 低信心或被遮住的關節不出數值。
- 3 秒可取消倒數，同時錄製原始影片與採樣姿態。
- 15 / 30 / 60 秒錄影上限；錄完可本機保存、回放或下載。
- 切頁／關閉相機會停止鏡頭；切到背景會停止錄影。
- AI 顯示的是實際處理頻率，不是相機拍攝 FPS。

**影片重要說明：**錄下的是原始影片，不是燒錄骨架的合成影片。網頁回放會按近似時間戳另行疊加姿態資料。影像與姿態不是專業硬體同步。

### 3. 影片分析
- 載入瀏覽器可解碼的 MOV / MP4 等影片。
- 0.25×、0.5×、1×、2× 回放；可選時間步距。
- 當前畫面分析，或選定起訖區間掃描；每次最多 900 個取樣時間點。
- 掃描可取消；遇到 seeked 逾時會停止，不將舊畫面當新畫面。
- 黃色：人工球路；綠色：人工桿頭；青色：人體手腕軌跡／比例參考。
- 兩點參考線、三點量角、復原、清除標記。
- 預備位／上桿頂點／擊球／收桿時點，人工標記後計算節奏比。
- 比例校正與慢動作倍率，計算 2D 桿頭投影速度。
- 截圖 PNG、逐幀分析 JSON、原始影片下載。
- 影片與分析存至本機紀錄，同一支影片再存會更新原紀錄。

**速度校正：**
先選「設定比例」，點選同一運動平面附近、已知長度物體的兩端，填入公分。
再選「標記桿頭」，於不同時間點選真正的桿頭。
每段速度 = 畫面位移（像素）× 公尺／像素 ÷ 真實秒數。
真實秒數 = 影片時間差 ÷ 慢動作倍率。
顯示的是相鄰標記間的平均投影速度，最大值不是雷達擊球瞬間速度。
出畫面方向的運動、透視、模糊、標錯點及變速影片都會造成誤差。
120/240 FPS 是拍攝幀率；匯出後的影片時間軸與慢動作倍率不能只靠選單自動推知。

時間步距不是解碼器保證的逐幀擷取；變動幀率影片與慢動作匯出尤其需要注意。
逐幀分析 JSON 可供程式處理，這一版尚未提供把該 JSON 重新載回影片編輯工具的介面。

### 4. 彈道與桿面
- 每球數據選擇。
- 3D／側視／俯視的示意重建。
- 桿面方向、球桿路徑與 Face-to-Path 示意。
- 全部擊球數據與來源標示。
- 需要 Carry + Apex + Offline 才畫完整示意；只有落點資料就只畫落點。
- 目前曲線是資料插值，不是含阻力／旋轉／風場的物理飛行模型，更不是手機自動追到的真實全程彈道。

### 5. 紀錄與比較
- 本機逐球資料、影片連結、編輯／刪除。
- 球桿、來源、文字搜尋。
- 同時選 2–3 球比較完整數據，有影片時可並排回放（非自動擊球時點同步）。
- 球桿距離分組與平均 Carry。
- CSV、JSON 匯出；JSON 資料檔不含影片本體和完整逐幀姿態。
- 列表顯示最新 200 筆，匯出包含全部紀錄；最多 2,000 筆。

### 6. 設定與裝置
- 名稱、慣用手、距離／速度單位、錄影長度、自動存檔。
- 相機／錄影／Web Bluetooth／IndexedDB API 能力檢查。
- CSV / JSON 匯入、格式驗證、重複資料略過。
- 讀取舊版 `golfShots` / `golfSessionShots` 手動紀錄，不刪舊資料。
- 溫度、濕度、氣壓作為**手動備註**，不假裝手機感測。
- 本機空間估計、持續儲存權限請求、刪除 v2 資料。

## 資料來源不能混用
- **相機姿態**：人體 2D 關鍵點／角度。這不是雷達數據。
- **影像估算**：人工標點、尺度與時間校正得到的投影速度；不自動寫入 Club Speed 欄。
- **手動輸入**：使用者填入。
- **外部匯入**：依檔案內容顯示；本程式不背書原設備精度。
- **計算值**：如 Smash = Ball Speed / Club Speed；Face to Path = Face Angle − Club Path。
- **示範資料**：只展示 UI，與本機真實紀錄分開，也不能當實測檔匯入。

數據以 SI 單位儲存：公尺、m/s、度、rpm、秒。
介面轉換：1 yd = 0.9144 m；1 mph = 0.44704 m/s。
空白保持 null，零是有效數字；有零與沒有資料不相同。

## 匯入規格
在設定頁下載 CSV 表頭範本。非範本格式的品牌報表，需先轉欄位與單位。
CSV 支援引號、逗號、換行欄位，單次檔案上限 5 MB。
欄位：
```
createdAt,club,source,carry_m,total_m,clubSpeed_mps,ballSpeed_mps,launch_deg,attack_deg,spin_rpm,spinAxis_deg,apex_m,flightTime_s,offline_m,clubPath_deg,faceAngle_deg,launchDir_deg,notes
```
右側偏移為正、左側為負；所有匯入數值採上述 SI 單位。
JSON 可使用本程式匯出的資料檔，或 `{ "units": {"distance":"m","speed":"m/s"}, "shots": [...] }`。
單球物件使用程式欄名，如 `carry`、`clubSpeed`、`spin`，而非 CSV 帶單位的欄名。
某一筆格式錯誤會拒絕整次匯入，不會偷偷略過錯誤資料。

## 隱私、瀏覽器與備份
本程式沒有把影片上傳到後端的程式碼，CDN 請求用於載入 MediaPipe 程式／模型。
依賴固定版本 `@mediapipe/pose@0.5.1675469404`，程式腳本有 jsDelivr／unpkg 兩個來源可重試。
這是 Legacy Pose 相容路徑，不宣稱是最新 MediaPipe Tasks 版本。
原始影片與逐幀資料使用 IndexedDB；小型擊球數據與設定使用 localStorage。
瀏覽器會決定空間配額與保留方式；無痕模式、清除網站資料、儲存空間不足、瀏覽器回收資料，都可能造成遺失。
請下載原始影片、個別分析 JSON 與擊球 CSV／JSON，不要把瀏覽器儲存當作唯一備份。
不同手機、不同瀏覽器、不同網站 origin 不會自動同步。
資料與單位的轉換僅協助觀察，不提供醫療、傷害風險或專業教練診斷。

## 實機驗收
- 用 HTTPS 網址開啟，確認有六個分頁。
- 在空白資料庫應看到「—」，按「體驗示範」才出現範例數字。
- 允許鏡頭權限，等待模型載入，確認骨架落在身體上。
- 錄一段短片，停止並回放，確認能存檔、下載與從紀錄重新開啟。
- 以尺寸已知的測試物、固定時間間隔，驗證比例標定流程；不要用未校正結果判定真實桿速。
- 匯入自己的雷達資料前先轉成範本欄位與單位。
